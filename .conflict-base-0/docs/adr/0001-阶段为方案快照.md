# 阶段是方案的快照，而非引用

确认一个计划时，每个阶段复制所属方案的营养目标，而不是保存方案 id 的引用。#4 需求 7 要求修改尚未执行的阶段时不改动已确认的记录；若阶段引用共享的方案，改一个阶段会同时改掉引用同一方案的其它阶段，并且历史数值会随方案漂移。代价是同一方案的数值会在多个阶段之间重复存储。

**Status**: accepted

## Considered Options

- **引用方案 id**：更 DRY，一份方案只存一份目标。但编辑会串改，且已确认的历史记录会随方案变化而变动，直接违反需求 7「保留已确认的实际执行记录」。
- **快照（已选）**：阶段自持目标。编辑互不影响，历史可冻结，代价是数值重复。存储预算 16 MiB，单个阶段的目标字段只有 6 个数值，重复可接受。
